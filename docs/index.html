Install

  1. Download the latest Paste release (a .dmg) and open it.
  2. Drag Paste to Applications and open it. It is signed and notarized by Apple, so macOS opens it without a warning.
  3. Allow Accessibility when the Welcome window asks. This is the only permission Paste needs. It then walks you through adding your first Binding.

Needs macOS 26. Paste checks GitHub for updates and installs them itself.

Build it yourself

Needs macOS 26 and the Swift toolchain (Command Line Tools are enough).

git clone https://github.com/matthewpeters-extended/paste.git
cd paste
./setup-signing.sh
./build-app.sh
cp -R build/Paste.app /Applications/
open /Applications/Paste.app
